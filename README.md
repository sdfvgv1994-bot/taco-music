# 🎵 taco 歌單

**https://sdfvgv1994-bot.github.io/taco-music/**

把喜歡的 YouTube 歌收成歌單，用 YouTube 官方嵌入播放器連續播放。手機、電腦打開就能用，不用登入。

- 貼上 YouTube 影片、Shorts、分享連結或**播放清單**連結就能加入（可以一次貼很多個）；播放清單會展開成一首首歌
- 上一首／下一首、🔀 隨機、🔁 全部循環／🔂 單曲循環／➡ 不循環；每首可以上移、下移、刪除
- 上傳者不開放嵌入的歌會標成「無法播放」並自動跳過
- 歌單存在這台裝置的瀏覽器裡，用「備份碼」搬到另一支手機
- **裝到手機桌面**：Android 的 Chrome 按「安裝到桌面」；iPhone 用 Safari 的「分享 → 加入主畫面」
- 螢幕保持亮著；瀏覽器支援時，鎖定畫面和耳機按鍵也能換歌

## 說明
- 只用 YouTube 官方的嵌入播放器播放，**不下載任何影音**，所以需要網路
- **Android 推薦用 Edge**：打開網址後「加到主畫面／建立捷徑」，鎖螢幕、切到別的 App 都會繼續播，播完自動接下一首，通知列也有播放控制（10/22 實測）
- Chrome 等其他瀏覽器在鎖螢幕或切到別的 App 時，通常會停止播放（嵌入播放器的限制）

## 程式
| 檔案 | 內容 |
|---|---|
| `index.html` | 畫面與樣式 |
| `core.js` | 規則：解析 YouTube 連結、歌單順序、備份碼（不碰畫面，測試也用它） |
| `app.js` | 畫面、YouTube IFrame Player API、存檔、安裝到桌面 |
| `sw.js`、`manifest.json`、`*.png` | 裝到桌面用的 App 檔案 |

main 有改動時，GitHub Actions「網站上線」會先跑測試（`pytest`，需要 node），通過才更新網站。
